# 项目目录结构说明

## 核心项目目录
- app/ - Next.js应用主目录
- backend/ - Python后端服务
- components/ - React组件库
- config/ - 配置文件
- docs/ - 项目文档
- hooks/ - React Hooks
- lib/ - 工具库
- services/ - 服务层
- types/ - TypeScript类型定义
- utils/ - 工具函数

## Archive目录结构

- archive/documentation-backups/ - 文档备份

- archive/standardization-reports/ - 规范化报告
- archive/temporary-files/ - 临时文件
